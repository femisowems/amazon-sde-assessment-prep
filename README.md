# Amazon SDE Online Assessment — Prep Research

Research notes and a preparation guide for the current (2025–2026) Amazon Software Development Engineer (SDE) online assessment on HackerRank.

This is general preparation material only. It contains **no leaked assessment questions or answers**, and no information about any individual's application, requisition, or assessment. It is not affiliated with Amazon or HackerRank.

## What's inside

- **[REPORT.md](REPORT.md)** — the full research report:
  - The current format: a timed coding challenge (one traditional problem + one code-repository problem with a built-in AI assistant), a work simulation, and work-style surveys
  - Q1: problem patterns, difficulty, hidden-test scoring, and a 40-minute workflow
  - Q2: repo-task bug taxonomy, the AI assistant's limits, and a 60-minute tests-first workflow
  - Work Simulation: Leadership-Principles trade-offs that score well vs poorly
  - Work Style Surveys: forced-choice format and consistency traps
  - Logistics: proctoring, technical issues, results, cooldowns, and score reuse
  - A readiness cram plan with go / no-go signals and a prioritised checklist
  - Prompt kits for practice (Q1) and for the built-in Q2 assistant — see the appendix in REPORT.md

## Key takeaways

1. Trust the invite over public prep pages — several official pages still describe the older format.
2. Q1 is a single Medium to Medium-Hard problem: pattern fluency in JavaScript (hash maps, sliding window, BFS/DFS, binary search on answer) matters most.
3. Q2 is a throughput test: README → run tests → trace → smallest fix → re-run all. Choose the stack you use daily.
4. The behavioural sections are scored against Amazon's Leadership Principles and can decide the outcome — don't rush them.
